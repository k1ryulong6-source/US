## kosuge-2k — 小菅 2K 房间规划

`kosuge-2k/index.html` 是一个单文件 3D 房间规划工具（Three.js），用来规划小菅 2K（2F）的家具摆放和装饰。

- 打开方式：直接用浏览器打开 `kosuge-2k/index.html`（需要联网加载 Three.js）。
- 当前载入的是**示例 2K 布局**，不是房源的真实间取。请在「房间」里上传 SUUMO 的间取图作底图，用「两点定比例」校准后，按图修改房间尺寸和门窗位置。
- 功能：3D / 平面 / 人视角；拖动、旋转家具；碰撞和穿墙提示；到墙距离；量尺寸；墙色、地面材质；按朝向和时间模拟日照；自动保存到浏览器，可导出/导入方案。
