# US

## kosuge-2k — 小菅 2K 房间规划

`kosuge-2k/index.html` 是一个单文件 3D 房间规划工具（Three.js），用来规划小菅 2K（2F）的家具摆放和装饰。

- 打开方式：直接用浏览器打开 `kosuge-2k/index.html`（需要联网加载 Three.js）。
- 布局按 SUUMO 房源 100517788068（足立区足立2，201号室，2K 30.62m²，南向き）的间取图描出，按 6帖和室 = 364×273cm 换算，误差约 ±10cm。窗户、空调、阁楼栏杆、柜门等细节再按 VR 全景图的展开图校正过。
- 包含房东提供的固定设备：空调 2 台、洗衣机、阁楼（ロフト）和梯子、天袋、流理台、马桶、手洗池。
- 功能：3D / 平面 / 人视角（以参照小人的视线高度）；点选后拖动、旋转家具（手机上有浮动操作条）；碰撞和穿墙提示；到墙距离；量尺寸；墙色、地面材质；按朝向和时间模拟日照；自动保存到浏览器，可导出/导入方案。
- 精细化：洋室斜顶（山墙、原木梁、吊灯）、通往 1F 的楼梯井、铝合金推拉窗＋磨砂玻璃、木窗框、窗帘轨、窗外护栏、阳台栏杆、和室長押/柱/回り縁、6帖 祝儀敷き榻榻米、壁纸纹理、不锈钢流理台、马桶、手洗池、淋浴设备、插座（位置约略）。静态构件按材质合并，减少手机上的绘制开销。
